MarkdownLivePreview
===================

Preview your markdown as you type, right inside Sublime Text.

Quick start
-----------

Open a markdown file and run "MarkdownLivePreview: Open Preview" from the
command palette. The preview opens next to your file, follows whichever
markdown file you switch to, and scrolls along with it. Run the command again
to close it.

Settings: "MarkdownLivePreview: Open Settings".

There's no key binding by default; the README shows how to add one.

Issues and suggestions:
